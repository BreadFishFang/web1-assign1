Note

This page shows the notes that I learned about using HTML to create a simple webpage

Here is the list of tags that I learn in this course:

<html>
HTML is the root element of an HTML page. We need to use <html> at the begining and </html> at the end of our .html file
<title>
Title is the website's main title, which appears in the browser's title bar or tab. And it is a part of the head element.
<body>
Contains the visible content of the HTML page. There can be only one body element in a document.
<header>
Header is a container for introductory content. Anything in header will show at the top of the page.
<main>
Main is the main content of the page. It is in between the header and footer.
<footer>
footer is a container for the footer of the page. There can be only one footer element in a document. Anything in footer will show at the bottom of the page.
<nav>
Navigation is oftem organized in lists for easier styling.
<ul>
ul is an unordered list.
<li>
li is a list item. li tags are used to organize the links into a list. We put li in ul to create an unordered list.
<a>
a is an anchor tag that creates a hyperlink. If we need to create a hyperlink, we use the a tag.
<h1>
h1 is a tag that represents the most important heading.
<h2>
h2 is a tag that represents the second most important heading
<h3>
h3 is a tag that represents the third most important heading
<p>
p is a paragraph tag.
<article>
Article should always contain a heading tag (h2-h6)
<img>
Img is an image tag, the image element need to creat a folder for images.
