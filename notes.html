Note

This page shows the notes that I learned about using HTML to create a simple webpage

Here is the list of tags that I learn in this course:

  • <html> - The root element of an HTML page
  • <title> - Specifies the title of the HTML page
  • <body> - Contains the visible content of the HTML page
  • <header> - Header is a container for introductory content
  • <main> - main is the main content of the page
  • <footer> - footer is a container for the footer of the page
  • <nav> - Navigation is oftem organized in lists for easier styling
  • <ul> - Represents an unordered list
  • <li> - li tags are used to organize the links into a list
  • <a> - a tag creates a hyperlink
  • <h1> - h1 is a tag that represents the most important heading
  • <h2> - h2 is a tag that represents the second most important heading
  • <h3> - h3 is a tag that represents the third most important heading
  • <p> - p is a tag that represents a paragraph
  • <article> - Article should always contain a heading tag (h2-h6)
  • <img> - Represents an image
